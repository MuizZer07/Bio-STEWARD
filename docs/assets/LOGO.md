# The Bio-STEWARD logo

A shield (integrity) with a green check mark (a passed check) over a faint DNA double helix (biology), on a
teal-to-indigo gradient.

| File | Use |
|---|---|
| `logo.svg` | the mark alone: favicons, icons, small places |
| `logo-wordmark.svg` | the mark and the name; its colour follows the reader's light or dark theme |
| `logo-wordmark.png` | the same at 2×, for places that need an absolute image URL (PyPI) |
| `favicon.png` | the documentation site's favicon |

The VS Code extension draws the same mark in `editors/vscode/scripts/figures.mjs` (`icon()`).

Colours: gradient `#0f8a8c` → `#4b4fd8`, check `#22c55e` with a white edge, name `#0b6f72` (light) / `#4fd1c5` (dark).
