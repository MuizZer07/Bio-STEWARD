# Session handoff

Written when a session ends (constitution, Article VIII), by `steward session close`: the next session reads this
first (`steward session start`). One file, replaced at each handoff, within its word budget (default 600); history is
in version control. It links to the records and copies none of them.

## State
Version, branch, last commit, and the last test result as reported.

## Next
One to three steps in order, each with its task ID.

## Open decisions
Questions waiting for the owner, each phrased so it can be answered in one line. A decision is recorded in
DECISIONS.md, never here.

## Open items
Findings, exchange items and uncommitted files, by ID only.

## Working agreements
How the owner asked this work to be done, learned in the session (verbatim where possible, with the date).

## Read first
At most five links, in order.

## Signature
Date · handoff · harness and version · provider · exact model ID (or unknown) · limitations
